# Test vectors for the SCS plugin pipe protocol (PROTOCOL.md). Read by the C++ tests and the C# tests.
#
# Line kinds (blank lines and lines starting with '#' are ignored; lines end with LF):
#   pipe-name <name>
#       The pipe name both sides must use, taken literally (no escapes).
#   payload <to-host|to-plugin> <ok|bad> <payload>
#       <payload> is everything after the single space that follows the verdict. Escapes: '\\' is one backslash,
#       '\xNN' is the byte with hex value NN. 'to-host' payloads are parsed as plugin-to-host messages, 'to-plugin' as
#       host-to-plugin messages. ok: parses, and encoding the parsed message gives the same bytes. bad: protocol error.
#   frame <ok|bad|partial> <hex>
#       <hex> (upper case, no spaces) is the whole byte stream given to a fresh frame reader, length prefix included.
#       ok: exactly one frame comes out and no byte is left. bad: the reader reports a protocol error.
#       partial: no frame and no error yet (the reader needs more bytes). Frames say nothing about payload content.
